# 東京都営バス インタラクティブマップ＆時刻表ビューア

東京都交通局が公開しているGTFSオープンデータおよび国土地理院地図タイルを活用した、東京都営バス（都バス）の路線図・バス停マップ・発車時刻表をインタラクティブに閲覧できるWebアプリケーションです。

---

## ⚠️ 重要なお知らせ・免責事項

- **非公式サービスです**: 本サービスは個人によって開発・運営されている非公式のWebアプリケーションであり、東京都交通局および東京都とは一切関係ありません。
- **臨時便は含まれていません**: 本サービスで提供する時刻表および運行ルート情報は、GTFSデータの定期ダイヤ（平日・土曜・休日）のみを対象としています。**臨時便、イベント時等の特別運行、運休情報には対応しておりません**。
- **正確な運行情報について**: 実際の運行状況、遅延情報、臨時便、最新の運賃等につきましては、必ず[東京都交通局公式ホームページ（都バス運行情報サービス tobus.jp 等）](https://tobus.jp/)をご確認ください。

## 🌟 主な機能

1. **エリア別軽量読み込み**
   - 「23区エリア（都心部・東部）」と「多摩エリア（青梅支所管轄）」にデータを分割。
   - 必要なエリアのデータのみをオンデマンドで取得することで、軽量かつ高速なページ読み込みを実現しています。

2. **インタラクティブマップ（Leaflet & 国土地理院地図）**
   - 全都営バス停留所を地図上にプロット（ピン表示・クラスタリング対応）。
   - 国土地理院の「標準地図」と「淡色地図」を切り替え可能。
   - 停留所を選択すると、その停留所を経由するすべての系統（路線）を一覧表示。

3. **路線・運行系統の可視化**
   - 系統を選択すると、地図上に運行ルート（走行軌跡ポリライン）を鮮やかにハイライト表示。

4. **基準時対応の時刻表表示**
   - 基準時設定機能（デフォルトは**現在時刻**、指定時刻・平日/土曜/休日の切り替え可能）。
   - 基準時刻の直後に出発する便をハイライト表示し、スムーズな乗り換えや出発確認をサポート。
   - 個別の便（Trip）を選択することで、始発停留所から終点停留所までの全停留所通過予定時刻表をタイムライン形式で表示。

5. **バス停クイック検索**
   - 画面左上の検索窓から、バス停名によるインクリメンタル検索・該当位置へのジャンプが可能。

## 🛠 技術スタック

- **フロントエンド**: HTML5, CSS3, Vanilla JavaScript (フレームワーク非依存)
- **地図ライブラリ**: [Leaflet](https://leafletjs.com/) 1.9.4, [Leaflet.markercluster](https://github.com/Leaflet/Leaflet.markercluster) 1.5.3
- **アーカイブ展開**: [JSZip](https://stuk.github.io/jszip/) 3.10.1 (路線・便ごとの個別JSONをクライアント側でオンデマンド解凍)
- **地図タイル**: 国土地理院 背景地図（標準地図 / 淡色地図）
- **バスデータ**: 東京都交通局 公共交通オープンデータ（GTFS形式）

## 🚀 ローカル環境での起動方法

本アプリケーションは静的HTML/CSS/JavaScriptおよびJSON/ZIPデータファイルで構成されているため、静的ファイルサーバーを起動するだけで動作します。

### Python を使用する場合 (Python 3.x)

```bash
# プロジェクトのルートディレクトリで実行
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` にアクセスしてください。

### Node.js (npx serve / http-server) を使用する場合

```bash
npx serve .
# または
npx http-server -p 8000
```
